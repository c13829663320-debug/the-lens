## 4. 使用或新增的公共接口

- `systems/model.js` 继续导出 `createState`、`validateState`、`GameModel`；当前存档 schema 为 `version: 2`。行为接口包括 `observe(objectId, mode)`、`attempt(optionId, mode)`、`advance()`、`tick(seconds, mode, paused)`、`setArtwork(strokes)`、`setSetting(key, value)` 和 `setBrightness(value)`。
- `ui/draw.js` 新增导出 `containFrame(image, x, y, width, height)`，用于图片留白框和触屏坐标统一。
- `platform/browser.js` 与 `platform/wechat.js` 的 `createPlatform().size()` 返回 `{ width, height, dpr, safe }`；`safe` 是逻辑像素坐标。
- 两个平台的 `video(url, onEnd, onError, onReady, options)` 使用 `options.muted`、`options.volume` 和 `options.topInset`；取消操作不重复调用结束或错误回调。
- `systems/audio.js` 保持 `AudioSystem.apply(settings)`、`environment(mode)`、`cue(type)`、`pause()`；环境状态名为 `reality`、`memory`、`cave`、`ending`。
- `ui/game.js` 仅导出 `Game`。`sceneFrame()`、`movePlayerTo()` 和 `interactAt()` 是内部实现，不作为跨窗口公共 API 扩展。
- 本窗口没有新增服务器 API、云存档 API、账号接口或远程媒体写入接口。
