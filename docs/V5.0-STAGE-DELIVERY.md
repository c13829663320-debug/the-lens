## 五、使用的公共接口

本轮没有新增或改变公共接口，也没有改动存档 `version: 2` schema。客户端远程媒体只收紧已有 manifest 的消费条件，不改变服务端字段或路径。当前代码实际使用的接口为：

- 状态/剧情：`GameModel.scene`、`advance()`、`observe(objectId, mode)`、`attempt(optionId, mode)`、`tick(seconds, mode, paused)`、`setArtwork(strokes)`、`setSetting(key, value)`、`setBrightness(value)`。
- 存档：`SaveStore.load()`、`SaveStore.save(state)`；存档状态 schema 为 `version: 2`。
- 音频：`AudioSystem.apply(settings)`、`environment(mode)`、`cue(name)`、`pause()`；环境状态为 `reality`、`memory`、`cave`、`ending`。
- 平台：`createPlatform().size()` 返回逻辑像素尺寸、安全区及 DPR；`video(url, onEnd, onError, onReady, options)` 负责视频回调与选项。
- 资源：`Assets.load(path)`、`retain(paths)`、`get(path)`；关卡资源定义来自 `data/chapter.js`。
- UI：`ui/game.js` 导出 `Game`；本次没有把内部命中区或布局方法提升为跨模块 API。
