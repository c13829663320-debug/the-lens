# 《透镜 THE LENS》小游戏 PRD · V1.0

## 产品与交付目标

将用户最终剧本转译为可操作的横屏微信小游戏。首要交付是能开始、探索、切换现实与历史影像、发现线索、完成环境推理并保存恢复的完整流程。使用原生 Canvas 2D 作为微信小游戏渲染基础，提供浏览器预览适配以便当前环境核验；避免引入当前未安装的大型引擎编辑器。服务器使用可部署到阿里云 ECS 的独立 Node.js 媒体服务，客户端本地存档不依赖服务器。

目标体验约 15–25 分钟，可随时暂停。原片五分钟的镜头顺序保留，观察和尝试由玩家完成。固定剧情关键节点不伪装成多结局选择。

## 体验支柱

| 支柱 | 玩家做什么 | 反馈与主题价值 |
| --- | --- | --- |
| 观察 | 查看现实物件、位置、炭灰、风与裂隙 | 线索可回看，目标逐步更新 |
| 对照 | 切换同一空间的现实与旧影像 | 旧影像提供位置关系，不修改实体碰撞和物品 |
| 尝试 | 取罐头、对照五点、选择杠杆支点、画下痕迹 | 不正确操作指出可观察现象，可重试 |
| 记忆 | 接近旧档案、画师过程、救援留下的画 | 过去的过程与自己的行动形成呼应 |
| 余韵 | 小花看见实体痕迹、主动观察 | 片尾只保留片名，不给主题总结 |

普通探索循环：明确目标 → 观察真实物件 → 查找历史对应 → 记录差异 → 通过实际物件完成操作 → 更新目标与本地存档。洞内循环不再依赖投影：触摸、画画、比照真实星空、感受风向、选择借力位置。

## P0 验收范围

- 标题/开始/继续、可退出菜单与暂停。
- 配置驱动场景切换、至少一个完整探索闭环；交付推进到原作开放结尾，扩展章节保留相同系统。
- 现实/影像切换、明确视觉/文字状态，原作电量连续性及洞内永久断电。
- 至少三个有意义的对象、重复点击不重复发放线索，线索记录可回看。
- 食品区环境推理、洞内观星/物理观察与操作；错误可重试。
- 手势字幕/叙事系统，近似默片的角色表达；音频、字幕与动画简化设置有效。
- 本地版本化存档，包含章节、场景、线索、谜题、关键操作、设置、电量与时间；损坏提示和恢复策略。
- 章节完成与固定片尾反馈，退出/后台/资源失败不使流程永久卡死。

P1 用经过审核的独立角色、美术近景和真实 CG 替换保守表现，加强连续镜头与声音。P2 幕后档案和更多可选观察不阻碍主流程。不做签到、抽卡、商城、成长数值或无关账号系统。

## 核心规则

透镜只显示历史，不创造食品、桥梁或可依赖的实体。切换有短暂镜缘变化和音效；简化动画模式取消明显过渡。电量在运行中的叙事时间耗损，高亮影像更快；无按次扣点、冷却、补电和付费能量。当前游戏化曲线：S08 前按 `battery × exp(-rate × seconds / 100)` 持续指数递减，有限探索时间内保持正电而不回充；S08 改为线性耗电，进入 S09 按原作叙事时间彻底耗尽。运行中不同状态的 rate 分别为现实 0.015、低亮影像 0.035、高亮影像 0.1。这些是游戏参数，非原片给出的真实电池测量值。后台与暂停不计时。断电是永久故事事件，并保存状态。

S01 的 `crowd`、S02 的 `display`、S03 的 `painter`、S04 的 `oldArchive` 为必要线索；必须实际举起透镜查看后才能推进，不能只在现实点完对象绕过核心机制。

罐头题答案来自历史货架位置与现实锈蚀框架、碎石关系。观星题由可拖动的无源镜缘五点与五颗真实星点对照；绘画题必须接收玩家的实际笔画，不能用“点击按钮=已经画好”的固定演示进度。清石题依据风、尘土、可借力支点与木枝；错误操作给出现象反馈。

## UI 与可访问性

横屏以 16:9 设计构图，适配常见 16:9、19.5:9、20:9 和平板；背景等比铺放，重要线索按可见安全构图重新定位。微信安全区用于四周 HUD 留白，触控热区目标至少 44 CSS 像素，触控坐标统一转换至逻辑画布空间。实际适配情况必须写入测试报告。

HUD 显示当前目标、透镜状态和暂停入口。线索册与章节地图从暂停或边缘小入口访问。界面采用灰白文字、暗色纸感/玻璃底与少量暖色发现反馈；不用科技蓝面板或全屏滤镜冒充历史画面。

字幕设置只控制角色动作字幕与演出文字；必要目标、互动提示与错误说明保持可见。所有音频可关，音量、震动、简化动画选项独立保存。声音不是解谜唯一信息来源：风向配合尘土视觉，救援配合画面/文字，投影断电有明确状态。

设置含重新开始章节、隐私与制作信息。当前全流程作为一个完整章节，重开会保留设置并回到 S10 新旅程入口，清除本章线索、谜题和画迹。继续功能仅依据通过校验的真实本地存档；写入失败明确提示，禁止显示虚假的“已保存”。存档 schema 为 version 2，`artwork` 保存玩家归一化画线坐标，每点在 0–1 范围，便于不同屏幕比例恢复并在小花查看新画时展示；只画出有效笔迹后才记录新画线索。
