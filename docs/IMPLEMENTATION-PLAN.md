# MVP 实施计划与验收证据

## 已完成底座与当前约束

代码按原生微信小游戏 Canvas 2D、配置数据、轻量状态系统组织；媒体服务位于 `server/`，仅提供健康检查、只读本地 CG manifest 和媒体 Range。服务器无账号、云存档或支付逻辑。客户端存档是 P0 本地 version 2 存储，保存归一化玩家画迹。`server/` 的 `node --test test/*.test.mjs` 已在 Node 22.23.2 通过 2/2；这只是 HTTP 服务自动测试，不代表微信真机测试或 CG 已生成。

2026-10-17 本地复核：项目 `npm test` 35/35 通过，加后端 2/2。项目包含平台视频 mock 测试（`tests/platform-video.test.js`），覆盖可缩放跳过空间、静音/音量传递、加载/整体超时、取消清理和原生 onStop 重入只回调一次；这验证适配代码契约，不能代替微信真机视频组件测试。其余项目测试包含必要影像、耗电曲线、绘画有效性、归一化画迹恢复与输入边界、设置保留、存档异常与完整剧情流程。

## 顺序

1. **工程检查与资源索引**：读取 `素材清单.csv`，保留 SHA-256；生成裁切任务表，原 PNG 只读。输出缺失/待补资源清单。
2. **渲染骨架**：建立逻辑画布、安全区、输入坐标转换、场景栈、暂停/设置、加载失败兜底。用一张 S01 黑白图完成标题→入场→退出。
3. **透镜状态**：现实/显影对照、P01 四状态、投影音频与断电状态；S01 crowd、S02 display、S03 painter、S04 oldArchive 是必要影像线索。S08 前 `battery × exp(-rate × seconds / 100)` 持续耗电且防提前软锁，S08 线性，S09 归零；所有实际耗能、切后台暂停和断电写入测试日志。原图不是严格同构素材，完美配准的 CG/场景是后续美术验收项。
4. **配置化叙事**：按 `SCENE-CONFIG.md` 写章节、交互、线索、手势字幕、固定演出；避免剧情硬编码到一个页面。
5. **首个闭环**：S01→S02 完成罐头。检查至少三个有意义对象、线索册、错误反馈和场景保存恢复。
6. **固定转译**：接入 S06→S05；断桥救援不得用随机失败改变剧本。加入 S07、S08。
7. **洞内根实现**：画布绘线记录救援画、五点观星对照拖动、风/尘视觉、支点选择、木棒撬石。所有成果必须由手势/观察实际产生，禁止固定“完成”按钮冒充。
8. **开放结尾**：S09→小花演出、片尾两秒风声和片名。片尾演出结束后才返回标题。
9. **资产与 CG**：用户生成后导入独立命名的图片；Seedance 视频只在实际可调用 API 与人工审核后加入 manifest。远程资源失败保留静态场景。
10. **测试与打包**：逻辑状态 node tests、浏览器预览、多比例触控、微信开发者工具预览和真机由拥有 AppID 的团队执行；记录设备、版本、日期、结果。

## 存档模型（version 2 字段示意）

```json
{
  "version": 2,
  "chapter": "ch01",
  "sceneId": "S09",
  "battery": 0,
  "brightness": 1,
  "lensAcquired": true,
  "clues": ["S09_drawing"],
  "solved": [],
  "choices": {},
  "completed": false,
  "artwork": [[[0.2, 0.2], [0.4, 0.5]], [[0.6, 0.4], [0.8, 0.7]]],
  "settings": {"audio": true, "subtitles": true, "volume": 0.35, "vibration": true, "lowMotion": false},
  "updatedAt": "2026-10-17T00:00:00.000Z"
}
```

上例仅示意字段，不是可以导入的真实进度：实际 S09 存档必须同时包含所有此前已完成场景所需线索、谜题和合法选择。`artwork` 最多 80 笔，每笔 2–1000 点，各坐标 0–1；至少两笔且总归一化长度 >0.15 后才能记录新画线索。写存档前校验版本、枚举、数字范围、数组上限和线索 ID；写备份候选并读回成功后再替换主键，采用 checksum 检测损坏。解析失败提示恢复/新旅程，不静默伪造进度。时间戳只作最近保存记录，不用来让离线时间消耗电量。version 1 与 version 2 不兼容时按异常恢复策略处理，不把旧画迹伪造为新画迹。
