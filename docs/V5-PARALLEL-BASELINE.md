## 实际接口契约

当前代码中的真实调用关系如下，窗口不得凭示例名称另造第二套接口：

- 场景与状态：`GameModel.scene`、`GameModel.advance()`、`GameModel.observe(objectId, mode)`、`GameModel.attempt(optionId, mode)`。
- 透镜：`GameModel.canLens`、`Game.toggleLens()`、`GameModel.tick(dt, mode)`；电量来自 `state.battery`，断电不回充。
- 存档：`SaveStore.load()`、`SaveStore.save(state)`；`Game.save()` 只在成功读回校验后显示保存状态。
- 音频：`AudioSystem.apply(settings)`、`environment(mode)`、`cue(name)`、`pause()`；已知状态为 `reality`、`memory`、`cave`、`ending`。
- 资源：`Assets.load(path)`、`Assets.retain(paths)`、`Assets.get(path)`；运行时路径必须来自 `data/chapter.js` 或资源映射。
- 媒体：`data/media.js` 的 `baseUrl/clips/sceneClips/manifestPath`；远程媒体失败必须回退静帧，未批准 CG 不进入生产 manifest。

## 统一剧情与状态边界

角色名称固定为阿迟、小花、族长；项目中不得出现“阿禾”。透镜只能显现过去，不能生成食物、修复现实或承重。主线顺序是 `S10 → S01 → S02 → S06 → S03 → S04 → S05 → S07 → S08 → S09 → 小花开放结尾`。S05 救援结果固定；S09 透镜断电后依靠画迹、星点、风尘和木枝推进；片尾不显示阿迟去向，不增加解释字幕。
