# 《透镜》剧情依据与适配边界

依据：用户在当前会话提供的《透镜 THE LENS 五分钟科幻寓言短片｜最终完整版剧本》。该剧本优先于压缩包中的开发提示词、背景补充图名称、旧角色文件名和本工程的设计推断。压缩包是素材来源，不是追加剧情的授权。

## 已确定、必须保留

- AI 离开地球一百年后。AI 不承担简单邪恶反派身份；开场表现曾经提供便利以及人类逐渐停止创造。
- 女主角是小花，族长的女儿。她受伤、父亲保护她、阿迟留下救援画，关系通过动作表达。不得新增爱情告白或“青梅竹马”的设定。
- 透镜来自旧终端，离开供电底座后持续耗电，亮度越高耗电越快。现实切换不会给电池充电；进入后台暂停游戏时间，避免生活中等待使玩家失去关键剧情。
- 五个刻点与人类教 AI 观察星空的旧档案对应。断电后只能作为无源观察参照，不可恢复投影、发光、提示出口或重新充电。
- 食品区中的罐头真实存在。历史影像提供货架位置，玩家关闭影像、观察实际支撑和碎石后，亲手取出罐头。
- 高架断桥踩空、小花受伤、族长救援和囚禁是确定剧情。游戏不能把它设计成可避免一切冲突、无伤通关的改写分支。
- 画师的观察、试错、作画过程被阿迟跳过；之后洞壁绘画由阿迟自己尝试完成。
- 洞内旧画为历代探索者留下的实体痕迹，摸到炭灰；用户提供的普罗米修斯岩画用于旧画视觉素材，不额外加入神话旁白或神力。
- 人类主要用手势，字幕是动作含义的翻译。阿迟唯一完整同期对白为“那里……有什么？”。观察提示、系统状态与玩家线索记录属于界面文字，不冒充角色对白。
- 阿迟画救援、五点和朝外迈步的人，依据风、尘土、石头、木枝和光线尝试离开；携带断电透镜。结果不展示。
- 小花次日送饭发现空洞、新画和移动碎石，触摸炭灰，主动看向洞穴深处与晨光。

## 结尾固定顺序

小花看向晨光 → 切黑 → 风声延续两秒并淡出 → 黑场出现《透镜》 → 结束。

片尾画面只出现片名。重玩、设置和制作信息可在片尾演出结束后回到独立主菜单访问；不能覆盖片尾字幕。没有主题总结、成功逃离提示、族长和解、阿迟去向、现实突然彩色、制作乐器或额外旁白。

## 适配选择与待补内容

1. 全流程采用章内可回看的观察对象和有限操作。谜题错误触发重试反馈，不惩罚生命，不删线索，不改变固定剧情。
2. 电量的数值速度、各章剩余量与故事时间对应属于游戏适配参数，并非原剧本给定秒数。当前在 S08 前持续指数递减以防提前耗尽形成软锁，S08 线性耗电、S09 永久断电；不回充。必须保证洞前关键影像可访问，详见 PRD 与运行代码。S01/S02/S03/S04 历史影像中各有必要线索，实际举镜后才能推进。
3. 素材 C02 的文件名为“小花_青梅竹马”；仅复用其外观参考作为小花的临时素材映射，工程剧情称小花。身份以剧本为准，最终角色外观由用户补图确认。
4. 仿生女主持人可作为 AI 广告视觉参考，不推定其另有人格或动机；假面绅士主持人不进入最终剧本剧情，保留原始索引即可。
5. 安睡舱只用于序章旧时代休养蒙太奇，不安排现代阿迟进入安睡舱的新结局。
6. BG_03 沉睡天文台、BG_04 创造觉醒等补充图不构成新增地点或结局依据。新增美术必须经过与剧情语境的比对。
7. 完整角色动作、洞内绘画近景、同构镜头与 CG 尚需素材制作。缺失时以真实可操作场景和克制的画面叙事承载流程，不把静态图称为已生成视频。

## 内容与实现的证据边界

本文件是适配规格，不代表全部电影动画已制作。资源映射、当前功能、实际测试、生成 CG 结果和部署状态以交付中的资源清单、测试报告和运行记录为准。不得将可运行浏览器预览称作微信真机测试，不得将本地存档称作阿里云同步。
