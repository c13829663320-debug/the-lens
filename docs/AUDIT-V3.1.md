# V3.1 运行审计

记录时间：2026-10-17（Asia/Shanghai）。

本轮审计聚焦窄屏安全区、HUD 边界、CG 原生视频层和绘画输入边界。修复与验证结果如下：

- **HUD/CG 层级**：播放 CG 时由平台原生视频层接管画面，Canvas HUD 与底层场景 hit targets 暂停响应；视频结束、失败、跳过或超时均只回调一次并恢复 HUD。
- **微信视频安全区**：视频跳过控件根据屏幕宽度、`pixelRatio` 与动态 `topInset` 计算位置，避免刘海/状态栏遮挡；音量、静音、加载超时和整体超时均传入平台适配层。
- **Canvas 跳过按钮**：浏览器预览的跳过按钮保留在顶部安全区域，窄屏下不压住标题和场景交互。
- **modal 交互隔离**：CG、设置、线索册等 modal 打开时清空底层场景 hit targets，关闭后重新绑定，避免误触推进剧情。
- **窄屏/安全区范围**：已在浏览器预览检查横屏、窄屏、动态顶部留白、暂停/设置和触控绘线；这些检查不等同于微信开发者工具或真机验收。
- **开发者工具裁切修复**：微信 `safeArea` 在部分开发者工具版本中会以物理像素返回，而窗口尺寸仍是逻辑像素；平台层现在将安全区坐标归一化并限制在窗口范围内。探索页同时缩短横屏标题带、扩大场景带，并将透镜电量文字限制在画布底部安全线内，避免“透镜 · 100%”被截断或场景被放大裁切。

自动化结果：项目测试 **35/35**，媒体服务测试 **2/2**；`npm run check` 为 10 个场景、16 个背景引用、缺失 0；`npm run build` 成功，微信运行时约 3.73 MB。此前记录中的 34/34 是绘画输入边界补测前的合计，当前应以 35/35 + 2/2 为准。

浏览器流程已真实推进到 S09 洞穴前三条线索。仍未完成的人工流程包括：绘画提交、五点对星、结尾完整走通、微信开发者工具导入/编译和微信真机测试。S01 Seedance 视频仍是待美术批准的 draft，不能作为 canonical CG 或线上接入凭据。
