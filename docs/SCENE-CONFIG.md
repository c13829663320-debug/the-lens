# 场景配置表 · 原作流程版

顺序是可玩章节顺序：S10 序章蒙太奇 → S01 → S02 → S06 → S03 → S04 → S05 → S07 → S08 → S09 → 小花开放结尾。下表是原作场景与目标视听/交互规格，当前具体配置以 `data/chapter.js` 为准：MVP 的环境行动以线索与选择反馈承载，洞内绘画/观星接收真实拖动；完整逐帧动作、同构 CG、古典乐与角色录音是后续资源制作项，不因列在设计表中而算已制作。

现行 version 2 存档将玩家画迹保存在 `artwork` 归一化坐标（0–1），关闭/恢复与改变屏幕比例后仍可展示。S01 `crowd`、S02 `display`、S03 `painter`、S04 `oldArchive` 是必要历史影像线索，只有实际举镜观察才能取得。其余必要现实线索仍需同时收集，不能靠选择正确答案跳过观察。

## 关键状态与重试

现行状态字段为 `sceneId`、`battery`、`brightness`、`lensAcquired`、`clues`、`solved`、`choices`、`artwork`、`settings` 和 `updatedAt`，schema 为 version 2。画面 `mode` 是运行时 `reality|memory`，继续旅程从现实视图恢复；`battery=0` 时不能启动影像。`clues` 只追加唯一 ID，`solved` 与 `choices` 由实际完成写入。S08 前按 `battery × exp(-rate × seconds / 100)` 持续耗电，在有限时间保留正电避免必要影像被永久锁死；S08 线性耗电，进入 S09 永久耗尽，不回充。

S05 受伤和 S09 断电是固定事件，重试不能改变剧情因果；全流程在当前版本属于 ch01 一个章节，“重新开始章节”保留设置并回 S10 清空进度。后台暂停计时；音频失败写入错误提示并保留视觉提示。图片失败可重试加载，观察条目仍可使用。
