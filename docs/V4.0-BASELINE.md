## 本轮优先修复

1. **断桥认知冲突不足（P0）**：S05 的谜题要求 `S05_bridge` 影像线索，只有先举起透镜观察旧连廊，救援行动才可提交；新增模型测试覆盖只看现实线索时不能推进。
2. **探索退化为静态热点清单（P0/P1）**：场景显示阿迟位置、可触屏移动目标、渐进标签和近距离交互；小花与族长在对应场景出现为叙事位置标记。观察条目面板只允许回看已记录线索。
3. **场景构图与透镜反馈不足（P1）**：背景使用 `contain` 保留 16:9 原图构图；影像层增加边框、非实体提示、低电状态失真和现实对照条。
4. **音频状态不可表达（P1）**：音频总线增加现实、影像、洞穴、事故和片尾状态增益，切换同一状态不再停止并重播环境音；缺失的专用音源保留为待补资源，不伪称已完成。

## 当前限制

- 角色档案仍是概念缩略图，没有可安全使用的透明动作帧；本轮只绘制低干扰位置标记，不把档案图伪装成独立精灵。
- Seedance S01 仍为待审核 draft，未启用远程 canonical CG。
- 微信真机、正式 AppID、DNS/HTTPS 与 GitHub 推送仍未取得新的外部证据。
