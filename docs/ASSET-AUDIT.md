## 压缩与运行预算

43张转换图片总3,363,394 bytes；其中18张场景2,880,110 bytes，档案409,759 bytes，UI30,277 bytes，补充参考43,248 bytes。3段原创程序合成WAV总293,892 bytes；全部资源共3,657,286 bytes（约3.49 MiB）。这是未压缩文件合计，工程代码仍需一并统计；文档、原始PNG与工具不应纳入小游戏代码包。

JPEG采取完整全幅等比压缩，未人为裁掉关键内容，未添加蓝色滤镜或额外剧情。避免同时解码18幅背景；按当前场景加载现实/影像2张，每张1280×约723 RGBA解码约3.53 MiB，双图约7.06 MiB。低画质可只加载当前态并简化淡入。

音频为本工程原创程序合成占位音，不来自原作，不含配音或音乐版权声明：`assets/audio/ambient_wind_8s_v1.wav`（8秒风/机械底噪循环），`lens_switch_v1.wav`（0.38秒），`puzzle_success_v1.wav`（0.8秒）。均为16kHz、16bit、单声道；已通过WAV重新解码，尚未进行微信真机听感测试。循环首尾归零以减少接缝声。

## 重建

Python 3.10+与Pillow：

```text
python -m pip install Pillow
python tools/build-assets.py --source "解压后的透镜_图片素材包_20261016绝对路径"
```

可追加`--contact-sheet "工作目录/contact-sheet.jpg"`重建接触表。脚本不改输入包，固定命名与合成随机种子，输出CSV/JSON映射与运行时资产。每次重建后需重新执行人工视觉检查；机器可读映射不会伪称人工批准。
